# Data Job Market Analysis

## Project Overview
This project analyzes the United States data job market using Python and Jupyter Notebook. The analysis focuses on job opportunities, hiring trends, top companies, and in-demand technical skills for data-related roles.

The project uses real-world job posting data to generate business insights through data cleaning, exploratory data analysis (EDA), and data visualization.

---

## Objective
The main objective of this project is to:
- Analyze job opportunities in the data industry
- Identify top hiring locations and companies
- Discover the most in-demand technical skills
- Compare skill demand across different data roles
- Visualize job market trends using charts and graphs

---

## Dataset
Dataset Source:
- Luke Barousse Data Jobs Dataset

The dataset contains:
- Job titles
- Company names
- Job locations
- Salary information
- Skills required
- Remote work availability
- Health insurance information

### 3. Skills Analysis

## Key Insights
- Data Analyst roles are highly concentrated in major U.S. cities.
- SQL, Python, and Excel are among the most demanded skills.
- Remote job opportunities are increasing in the data industry.
- Several companies provide additional benefits such as health insurance.
